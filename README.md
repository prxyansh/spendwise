# SpendWise – Hybrid Expense Tracker

A mobile version of a web-based expense tracker, built with the **hybrid app approach**:
a standard HTML/CSS/JavaScript web app (`www/`) wrapped into a native Android app using **Ionic Capacitor**.

## Features
- Add, edit and delete expenses (amount, category, date, note)
- Monthly and all-time totals
- Category-wise spending breakdown with progress bars
- Filter by category and search by note
- Works fully offline – data is stored on the device (localStorage)
- Mobile-first responsive UI, safe-area support, native Android WebView shell

## Tech stack
| Layer | Technology |
|-------|------------|
| UI | HTML5, CSS3, vanilla JavaScript |
| Hybrid wrapper | Ionic Capacitor 7 |
| Native platform | Android (Gradle project in `android/`) |
| Storage | Browser localStorage (persists inside the app WebView) |

## Project structure
```
spendwise/
├── www/                  Web app (index.html, css/, js/)
├── android/              Native Android project generated by Capacitor
├── capacitor.config.json App id, name, web directory
├── package.json
└── .github/workflows/build-apk.yml   CI that builds the APK
```

## Run in a browser (quick test)
```bash
cd www
python3 -m http.server 8080
# open http://localhost:8080
```

## Build the APK

### Option A – GitHub Actions (no local setup)
1. Create a GitHub repository and push this folder to the `main` branch.
2. Open the **Actions** tab → **Build Android APK** runs automatically (or click *Run workflow*).
3. When it finishes, download `SpendWise.apk` from the **Releases** page (tag `apk-latest`) or from the run's *Artifacts*.

### Option B – Locally with Android Studio
Requirements: Node 20+, JDK 21, Android Studio (Android SDK 35).
```bash
npm install
npx cap sync android
npx cap open android        # then Build > Build APK(s) in Android Studio
```
Or from the command line:
```bash
npm run apk:debug
# output: android/app/build/outputs/apk/debug/app-debug.apk
```

## Install on a phone
Copy the APK to the device, allow *Install unknown apps* for your file manager, and open the file.
